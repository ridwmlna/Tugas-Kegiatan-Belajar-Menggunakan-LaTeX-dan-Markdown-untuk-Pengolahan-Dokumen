# Tugas-Kegiatan-Belajar-Menggunakan-LaTeX-dan-Markdown-untuk-Pengolahan-Dokumen
Dokumentasi proyek pembelajaran penggunaan LaTeX dan Markdown untuk mengolah dokumen matematika, meliputi konversi notebook Euler Math Toolbox (EMT), penyuntingan dokumen, penulisan ekspresi matematika, serta kompilasi menjadi dokumen PDF.
